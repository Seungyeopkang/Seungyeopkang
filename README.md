# Seungyeop Kang · 강승엽

[Homepage](https://seungyeopkang.github.io/) · [Google Scholar](https://scholar.google.com/citations?user=LyhTPfYAAAAJ&hl=en) · [Email](mailto:a01073553545@gmail.com)

My research focuses on efficient deep learning, particularly neural architecture search and model compression. I also study the reliability of zero-cost proxies for architecture selection.

I am also interested in compressing large language models for on-device inference through pruning, quantization, and low-rank approximation.
